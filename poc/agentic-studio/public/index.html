Architecture flow

  1. UI — Operator types a natural-language prompt
  2. Agent — Interprets intent via LLM (or heuristic) with full mdk-contract.json as context
  3. MCP tools — Calls get_worker_capabilities, get_fleet_telemetry, optionally execute_device_command
  4. App Node — JWT validation, RBAC, fan-out to ORK sessions
  5. ORK — Routes by deviceId, dispatches to worker
  6. Worker — Returns telemetry / executes command per mdk-contract.json
