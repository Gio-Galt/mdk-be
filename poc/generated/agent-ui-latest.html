Declared commands (mdk-contract.json)

  • reboot — Safely restarts the controller. Takes approx 2-3 minutes for the dashboard to respond again.
    Do not call sequentially within 5 minutes. Never issue this command more than once in a 15-minute window. Allow time for the boot telemetry to settle.
  • setPowerLimit — Adjusts PSU output.
    Never set below 2000W or hashboards may fail to initialize. Max is usually model-dependent (up to 3500W-4000W).
  • setPools — Updates the primary mining pool configuration.
